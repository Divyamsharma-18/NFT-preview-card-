## 🎨 What’s This Project?

This is your take on the “NFT preview card” design challenge from Frontend Mentor. ([frontendmentor.io][1])
You’ve built a sleek component that:

* Displays an NFT image with overlay hover effects
* Shows metadata like title, description, creator, and price
* Reacts elegantly on hover with subtle visual cues
* Is fully responsive — looks as good on mobile as on widescreen

All wrapped in a layout and visual style that say: *“I care about the details.”*

---

## ✨ Features You’ll Notice

* 👁️ Image overlay on hover: subtle darkening + view icon effect
* 💬 Metadata section: title, description, value (e.g., ETH), creator thumbnail
* 📏 Responsive dimensions: scales smoothly from mobile to desktop
* 🎨 Polished typography, spacing, and aesthetic-first styling
* 🛠 Built using HTML & CSS (maybe minimal JS if you added artsy interactions)

---

## 🧠 Tech Stack

| Technology     | Role                                                      |
| -------------- | --------------------------------------------------------- |
| **HTML**       | Semantic markup: card structure, image, metadata elements |
| **CSS**        | Visual styling: hover effects, layout, responsive rules   |
| **JavaScript** | (Optional) if you included interactive behaviour          |
